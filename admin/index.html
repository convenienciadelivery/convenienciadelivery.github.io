Como editar o cardápio

  1. Altere produtos, categorias, banners e dados da loja neste painel.
  2. Clique em Salvar alterações — os dados ficam no navegador (LocalStorage).
  3. A loja pública lê automaticamente as alterações salvas neste dispositivo.
  4. Para publicar em outro computador/hospedagem, use Exportar JSON e substitua os arquivos em data/.
  5. Altere o WhatsApp em Loja para receber pedidos no seu número.

⚠️ Importante para venda comercial

Troque a senha padrão em Configurações antes de entregar ao cliente. Configure WhatsApp, horários e taxa de entrega.

Pedidos salvos quando o cliente clica em Enviar pedido no WhatsApp. No GitHub Pages / mesmo site, aparecem automaticamente. Se abrir os HTML direto no PC, importe o arquivo JSON baixado no envio.
